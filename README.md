📸 Photography Studio Booking System
A full-stack web application built with Django to manage bookings for a photography studio. Developed as a hands-on training project covering front-end styling, back-end CRUD operations, and user authentication.

✨ Features:

🏠 Clean, styled home page with CSS and JavaScript form validation

➕ Add new bookings (customer name, event type, date, phone)

📋 View all bookings in a organized table

✏️ Edit existing booking details

🗑️ Delete bookings

🔐 User authentication — signup, login, logout

🛡️ Protected routes — only logged-in users can manage bookings

🛠️ Tech Stack
Backend: Python, Django
Frontend: HTML, CSS, JavaScript
Database: SQLite

🎓 Built as a project-based practical assignment for the Full Stack Web Development Training Programme.
